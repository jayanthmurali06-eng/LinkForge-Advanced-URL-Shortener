# LinkForge

LinkForge is an advanced URL shortener built with Python, Flask,
and SQLite.

## Planned Features

- Generate short URLs from long links
- Redirect users to original destinations
- Create custom aliases
- Track link clicks and visit statistics
- Generate QR codes
- Set link expiration dates
- Manage links through a dashboard
- Validate URLs and handle errors safely

## Technology Stack

- Backend: Python and Flask
- Database: SQLite
- Frontend: HTML, CSS, and JavaScript
- QR Codes: Python qrcode library
- Version Control: Git and GitHub

## Project Status

Currently in development.

## Local Setup

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Start the application using the instructions that will be added
   when the Flask application is implemented.
